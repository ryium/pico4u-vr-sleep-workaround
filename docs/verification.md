# Verification Guide (v0.3.0)

The application version is **0.3.0**. This release introduces a calm-night wizard interface redesign, structured error diagnostics with troubleshooting hints, and preserves active wireless connections during wireless setup (incorporating [fc513b4](https://github.com/nitda-lab/pico4u-vr-sleep-workaround/commit/fc513b4ce7f922e7c56a845f538191cfb112b55a)).

## Local run

```powershell
.\scripts\pnpm.ps1 install --frozen-lockfile
.\scripts\pnpm.ps1 dev
```

Windows installers are generated by `.\scripts\pnpm.ps1 build --no-sign` in `target/release/bundle/nsis/` and `target/release/bundle/msi/`.

## Automated verification

- **TypeScript & Linting**: `tsc --noEmit` typecheck passes; Oxlint reports 0 errors and 0 warnings; Oxfmt confirms standard code style across all 35 source files.
- **Vitest (16 tests)**:
  - `errors.test.ts` (4 tests): `toAppError` normalization from strings, objects, timeout errors, and AbortErrors; full bilingual coverage ensuring every `ErrorCode` has a localized title and at least one actionable hint in both Japanese and English.
  - `setupSteps.test.ts` (3 tests): Reducer state machine handling step transitions (`running`, `ok`, `failed`, `skipped`).
  - `settings.test.ts` (4 tests): Sequential settings saves, failure isolation, transport connection validation, and IP address retention upon wireless setup failure (fc513b4 regression test).
  - `async.test.ts` (5 tests): Timer and asynchronous operation helpers.
- **Rust (22 tests)**:
  - `connection.rs`: `parse_device_rows` with unauthorized/offline states, `probe_usb` matching, `wireless_candidates` prioritizing saved IPs, and `parse_wifi_on` flags.
  - `error.rs`: `classify_connect_reply` for Windows WSA codes (10061 refused, 10060 unreachable, auth failures) and `AppError` JSON serialization.
  - `adb_client.rs`: Protocol parser, fragmented streams, and rejection reasons.
  - `config.rs`: Timer bounds and legacy setting migration.
  - Format, test, and Clippy: `cargo fmt --check`, `cargo test --locked`, and `cargo clippy --locked -- -D warnings` all pass with 0 warnings.
- **Frontend build**: Vite bundle builds clean without chunk errors (`pnpm run build`).

## Headset checks for the reviewer

These need a physical PICO 4 Ultra headset:

- [ ] **USB authorization check**: Connect via USB without accepting the prompt on the headset. Verify that the "USBデバッグの許可" step fails with `usb_unauthorized`, displaying a prompt instructing the user to wear the headset and allow USB debugging.
- [ ] **Wi-Fi disabled check**: Turn off Wi-Fi on the headset in Settings. Run wireless setup and verify it halts at step 4 with `wifi_disabled` and guides the user to turn on Wi-Fi.
- [ ] **Wireless setup & disconnect**: Complete wireless setup successfully. Unplug the USB cable; verify that the connection status chip reflects wireless connection and IP address.
- [ ] **Active wireless setup idempotency (fc513b4)**: While already connected wirelessly (without USB connected), click wireless setup. Verify that the existing wireless link is not disrupted, no `tcpip:5555` command is issued, and the setup succeeds immediately (`already_connected`).
- [ ] **Headset reboot handling**: Restart the PICO 4 Ultra. Attempt auto-reconnect and verify that connection refused (10061) is detected as `wireless_refused`, guiding the user to plug in USB to re-initialize wireless ADB.
- [ ] **Operation & Power toggle**: Tap the large power button to start Keep Awake. Verify the gentle breathing glow animation and the elapsed timer counting up. Tap again to stop.
- [ ] **Auto-dimming**: Configure dim delay, start Keep Awake, and verify brightness reduces when the timer elapses. Verify stop cancels any pending dim.
- [ ] **Sheets (Settings & Logs)**: Open the settings sheet from the header gear icon and change theme or timer values; open the logs sheet from the bottom link and verify clear messages without debug mode, and full ADB details when debug mode is enabled.
