PICO 4 Ultra向けのVR睡眠（V睡）支援ツール「pico4u V睡ツール」のバージョン 0.3.0 です。画面デザインの刷新、既存無線接続の保護、およびエラー診断の強化を行いました。

## 主な変更点（v0.2.1-rc1 からの変更）

### 1. デザインの刷新（夜・休息テーマ）
- **ウィザード型ナビゲーション**: 「接続方法の選択」→「準備（チェックリスト）」→「操作（開始）」の3段階で、迷わず直感的に利用できるようにしました。
- **大型パワートグルボタン**: 画面中央に配置した大きな円形ボタンでスリープ回避の開始・停止をワンタップで切り替えられます。動作中は呼吸するように穏やかに発光します。
- **経過時間と減光タイマー**: スリープ回避の稼働時間と、自動減光が実行されるまでの残り目安時間を表示します。
- **設定とログのシート表示**: 設定画面とログ画面を下から引き出すシート形式に変更し、メイン画面をすっきり保ちます。
- **Charcoal UI 準拠のカラーパレット**: 心地よい睡眠環境を邪魔しないよう、淡いオフホワイトのライトテーマと深いチャコールネイビーのダークテーマを用意しました。

### 2. 無線接続の安定化と既存接続の保護
- 既に無線接続されている状態で「無線セットアップ」を実行した際に、接続を切断せず既存のリンクをそのまま維持して成功とするように改善しました（nitda-lab様の修正を取り込み）。
- セットアップに失敗した場合でも、前回保存されたヘッドセットのIPアドレスが消去されないように保護しました。

### 3. エラー診断の詳細化とわかりやすい案内
- エラーの原因（USBケーブル未接続、ヘッドセット側のUSBデバッグ未許可、ヘッドセットのWi-Fiオフ、ADB接続拒否など）を自動判定します。
- 技術的なエラーメッセージだけでなく、「ヘッドセットを被ってデバッグを許可してください」「Wi-FiをオンにしてPCと同じネットワークに接続してください」といった具体的な改善手順（ヒント）を日本語と英語で画面に表示します。
- 無線セットアップの進捗を5項目のチェックリストで1つずつ確認できるようにしました。

## ダウンロード

Windows x64 向けの `-setup.exe`（NSIS インストーラー）または `.msi`（WiX インストーラー）をダウンロードしてご利用ください。通常は `-setup.exe` を推奨します。

## 実機でのご確認のお願い

開発環境での自動テスト（Rust 22件、Vitest 16件、型チェック、フォーマット、ビルド）はすべて通過していますが、PICO 4 Ultra実機での無線接続・USB挙動についてフィードバックをお待ちしております。お気づきの点や接続に関する問題がありましたら、GitHub Issuesまでお寄せください。
